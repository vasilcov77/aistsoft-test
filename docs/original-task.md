# Исходный текст тестового задания

Разработать REST API на PHP для получения данных с ресурса https://checko.ru/ Оформить в стиле ООП без использования фреймворков. API должен содержать класс для внешних запросов (точка доступа с ресурсами) и класс получения данных с целевого ресурса. БД как и токены доступа к API можно опустить, но это будет плюсом, чтобы показать свои навыки. Наличие swagger интерфейса также будет плюсом. Разработка собственного интерфейса по желанию. Будем смотреть на понимание ООП, читабельность и чистоту кода, логику обработки ошибок а также взаимодействие с целевым ресурсом и обработку данных. Задание необходимо выложить на GitHub и предоставить ссылку
