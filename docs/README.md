Индекс. Читать по порядку при онбординге.

- [Исходное задание](original-task.md) — что требуется по ТЗ.
- [Приёмка](ACCEPTANCE.md) — карта «требование ТЗ → где реализовано» и чек-лист перед сдачей.
- [Глоссарий](GLOSSARY.md) — принятые термины, единый язык.
- [ADR-0001: обёртка над checko API](adr/0001-wrap-checko-api.md) — архитектура и обоснование.
- [ADR-0002: политика кэша](adr/0002-cache-policy.md) — TTL 1 час, ключ кэша, fail-open.
- [Контракт checko API и ошибки](checko-api-errors.md) — как распознаём успех/ошибку, лимиты.

- Swagger UI — `http://localhost:8080/docs/`, спецификация для UI — `/openapi.yaml`.
- `../README.md` — быстрый старт и краткое описание API.

## Правила

- Значимое архитектурное решение → новый ADR в `adr/NNNN-краткое-имя.md`.
- Новый термин → строка в `GLOSSARY.md`, тем же словом пользуемся в коде и обсуждениях.
- Изменение API → обновить `app/openapi.yaml` и `ACCEPTANCE.md`, если затронуто ТЗ.
