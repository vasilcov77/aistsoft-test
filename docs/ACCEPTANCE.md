# Приёмка: требование ТЗ → реализация

Карта соответствия исходному заданию ([original-task.md](original-task.md)). Помогает и при
разработке (ничего не забыть), и комиссии (быстро найти нужное в коде).

| Требование ТЗ | Где в проекте |
|---------------|---------------|
| REST API на PHP | Роутер и контроллеры под `/api/v1/` (`/company`, `/health`), JSON-ответы |
| ООП-стиль | Ядро из слоёв: Transport / Resource / Facade / DTO (см. ADR-0001) |
| Без фреймворков | `composer.json`: только Guzzle, PSR-интерфейсы, phpdotenv |
| Класс для внешних запросов («точка доступа с ресурсами») | Слой Transport — обёртка над Guzzle, работает с `ResourceInterface`, не знает домена |
| Класс получения данных с целевого ресурса | Классы-стратегии `Resources\*` + Facade, собирающий конвейер |
| Логика обработки ошибок | `ApiException` с фабриками + единый `ExceptionHandler` (см. таблицу в ADR-0001) |
| Взаимодействие с checko | `POST https://api.checko.ru/v2/<resource>`, JSON-тело, `key` из env, таймауты, ретраи на `ConnectException` |
| Обработка данных | DTO: immutable-объекты с валидацией, маппинг сырого ответа `/company` в домен (`Checko\Dto\ResponseCompanyDto`) |
| Swagger (плюс) | Спецификация `app/openapi.yaml`; Swagger UI — `/docs/` |
| БД / токены (плюс) | Кэш ответов в Valkey через PSR-16 (TTL 1 час, ADR-0002) |
| Собственная аутентификация | Осознанно не делаем: ключ checko живёт только на сервере, клиент его не передаёт и не может потратить наш баланс; API рассчитан на доверенный контур/демо |
| Собственный интерфейс (по желанию) | Демо-страница `GET /demo`: PHP-шаблон + Tailwind CSS + vanilla JS, карточка/JSON, история, ошибки |
| Реализованный ресурс checko | `/company`: `CompanyResource` + `ResponseCompanyDto` + `GET /api/v1/company` |
| Публикация на GitHub | Ссылка на репозиторий — в шапке README |

## Чек-лист перед сдачей

- [ ] `make up` + корректный `.env` → API отвечает на все ресурсы, заявленные в README (`/company`, `/health`).
- [ ] `app/openapi.yaml` актуален и совпадает с реальными роутами.
- [ ] Проверены все строки таблицы ошибок: 422 / 401 / 404 / 429 / 502 / 504.
- [ ] Ключ checko не попадает ни в ответы API, ни в логи, ни в ключи кэша.
- [ ] Повторный одинаковый запрос не идёт в checko (кэш работает, TTL 1 час).
- [ ] В `docs/checko-api-errors.md` подтверждены строки 402/403 на реальном ключе.
- [x] Демо-страница работает и показывает организацию по ИНН/ОГРН.
- [ ] README: актуальные команды запуска и примеры запросов.
- [ ] `docs/` соответствует коду (термины, ADR, эта карта).
